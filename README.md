# Intelligent Summarization of Website Content Using Transformer-Based Models

## Project Overview
This project focuses on summarizing lengthy website content into concise and meaningful summaries using Natural Language Processing (NLP) and the T5 Transformer model.

## Objectives
- Reduce lengthy website content into shorter summaries.
- Preprocess and clean text using Python.
- Evaluate summary quality using ROUGE metrics.
- Provide a simple interface for users to view summarized content.

## Technologies Used
- **Programming Language:** Python
- **AI/NLP:** Natural Language Processing, T5 Transformer
- **Evaluation:** ROUGE-1, ROUGE-2, ROUGE-L
- **Web Technologies:** HTML, CSS
- **Database:** SQL

## Key Features
- Text preprocessing and cleaning
- Transformer-based text summarization
- Summary quality evaluation using ROUGE metrics
- Simple web interface

## Project Structure
The repository contains the application file, HTML templates, SQL file, and project documentation.
